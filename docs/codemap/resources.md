# Kinetic Code Map: Source Files and Asset Folders

Part of the [Kinetic code map](../CODEMAP.md). Every file under `src/` that is not a Java class, and every asset and data folder.

## Source Files

|---|---|

## Asset Folders

| Folder | Contents |
|---|---|
| `src/main/resources/assets/kinetic/lang/` | `en_us.json` and `tr_tr.json`: key binding, NeoForge config and `kinetic.config.*` Arkea settings-screen texts. |
| `src/main/resources/assets/kinetic/shaders/lod/` | Instanced 16-byte geometry with packed light/water metadata; forward lightmap shading and Helion normal/light/unshaded-albedo output. |
| `src/main/resources/assets/kinetic/shaders/include/` | `lod_common.glsl`: uploaded-chunk coverage clipping and tile bounds (`terrainCoverageClip`; `terrainClip` adds the dithered tile fade), lightmap/cardinal lighting, render-distance fog, Ultra block texture detail (16 world-space pixels per block, fading out once a pixel gets smaller than the screen pixel) and water shading (sky reflection by view angle and gentle ripples). |
| `src/main/resources/assets/kinetic/textures/gui/` | `logo.png`: Kinetic brand logo for its settings screen; `logo.png.mcmeta`: enables linear filtering for that logo. |
| `src/main/resources/assets/kinetic/shaders/terrain/` | `compact.vsh`: the vanilla `core/terrain` vertex shader reading the compact vertex format (module `compactVertices`); the fragment shader stays vanilla. |
| `src/main/resources/assets/kinetic/warmup/` | `join_classes.txt`: classes `JoinWarmup` loads ahead of the first world join, one name per line, sorted; generated from a JFR recording of joins on Minecraft 26.3 (render thread class loads, without hidden and lambda classes and without other Aryston mods). |
